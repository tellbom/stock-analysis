# D+3 / D+5 长期与近期 RRF 推荐

运行当前信号日的双周期融合推荐：

```powershell
python scripts/run_dual_horizon_rrf.py --as-of 2026-10-09 --horizons 3 5
```

输出默认位于 `models/data/reports/dual_horizon_rrf_2026-10-09/`。

## 计算口径

- 每个周期分别训练两个 LightGBM 模型，复用 `run_d3_gate_once.py` 的长期/近期模型参数。
- D+3 只用原始收益标签 `ret_fwd_3d`，D+5 只用 `ret_fwd_5d`。标签为 `close(T+1+h)/close(T+1)-1`，从截至信号日的行情在内存中重新计算，以排除之后才观察到的收益。
- 长期模型使用通过 base 覆盖检查的因子，排除短历史资金流；近期模型使用可观察标签的最近 120 个交易日，并接入通过 recent 检查的资金流。
- Gate 保留 `A_MAIN`、`B_SHORT_BOOST`，再按 `1/(60+base_rank)+1/(60+recent_rank)` 进行 RRF 排名。
- 融合后的候选进入现有行业中性选择器：行业内前 3，只数上限 50。符合条件不足 50 时按实际数量输出。
- 特征构建失败、资金流全部被拒绝、预测覆盖缺失或资金流训练日期不足 80 日时停止，避免无提示地降级为长期单模型。

## 核验记录

`run_summary.json` 保存两周期的准确标签、训练日期、实际因子列表、资金流非空训练日数、预测覆盖和模型分裂次数。CSV 保存逐股票的两路排名、Gate、RRF 候选与最终名单。

本入口复用既有融合方法，补上此前临时 Ridge Excel 导出未接入的长期/近期流程，并扩展至独立训练的 D+5。旧临时导出不包含资金流，不能作为融合结果使用。

单日输出证明数据和模型链路已接通，不证明新增因子提高了准确率。D+5 接口复用不等于完成了 D+5 的独立样本外效果验证。
