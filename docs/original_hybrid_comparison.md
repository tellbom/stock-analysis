# 原版与混合的统一基线对照

## 当前混合是否真的训练了资金流

是。此前 `run_dual_horizon_rrf.py` 每个周期分别拟合长期、近期两个 LightGBM 模型。2026-10-09运行中，长期35列，近期40列；新增的5个资金流列在D3和D5近期训练中均覆盖120个成熟标签交易日，并有非零树分裂次数。它们实际参与了 `fit_final_model`，不是只写在Excel里。

RRF是预测后固定排名公式 `1/(60+base_rank)+1/(60+recent_rank)`，不训练融合权重。D3和D5互相独立，不跨周期融合。此前入口保存预测及训练审计，不保存或晋升这四个拟合对象到生产模型注册表。

但是，原交付模型是32因子Ridge，此前混合底座是35因子LightGBM。算法、因子、训练样本缺失值规则和窗口同时变化，不能据此归因资金流或RRF的增量效果。

## 本次已经实施的对照

新增 `scripts/compare_original_hybrid.py`，使用9月30日原批次，10月8日计划收盘入场：

| 实验组 | 长期预测 | 近期预测 | 排序和筛选 |
|---|---|---|---|
| ordinary | 原版Ridge32 | 无 | 原版行业最多3只、总数最多50只 |
| hybrid_no_flow | 共用ordinary的299只预测 | LightGBM32，无资金流 | RRF，同行业/总数限制 |
| hybrid_flow | 共用ordinary的299只预测 | LightGBM37，增加5列资金流 | RRF，同行业/总数限制 |
| hybrid_flow_score_gate | 共用ordinary的299只预测 | 共用hybrid_flow近期预测 | 分数Gate + RRF，同行业/总数限制 |

两个近期组训练日期、行集合、目标、参数、种子、股票池一致，仅增加五个资金流列。D3、D5各自两近期组共享35,883行、120个完整交易日，没有因资金流缺失而额外排除行。资金流和估值输入在信号日截断，市值按向后日期匹配。每个周期共用同一长期预测，没有为混合组换底座。

这是新建的受控混合实验，不是对10月9日35/40列LightGBM混合版本的原样复现。Gate诊断只使用分数层级，未额外加入事件/风险因子。9月30日没有实际交付这三个混合名单，所有混合收益均为事后重建实验。

## 最近一周结果

仅检查10月8、9、12、13日，等本金买入持有。净收益按毛收益减去双边共20bp估算。D3已完成，D5为假设13日提前退出的阶段收益，到15日才完成。
