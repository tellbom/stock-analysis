# 普通 D+3 与混合 D+3 的最近一周核对

`scripts/reconcile_d3_recommendations.py` 对已经冻结的推荐名单计算收益，不执行训练。

## 本次数据与口径

- 普通名单：2026-10-09 已交付的 Ridge D+3，50 只。
- 混合名单：同一信号日的长期/近期 LightGBM、资金流、Gate 和 RRF，43 只。
- 唯一目标为 `ret_fwd_3d`：`close(T+1+3)/close(T+1)-1`。
- 2026-10-12 收盘入场，2026-10-15 收盘完成 D+3。截至 2026-10-13 的结果属于阶段核对。
- 组合按入场时每只股票投入相同本金计算。毛收益为单股收益的算术平均。
- `net_if_exit` 是假设观察日收盘全部卖出后的收益，默认每边 10bp。它不是仍在持仓组合的已实现净收益。
- 基准为相同入场/观察时点的沪深300指数。没有基准价格时不计算超额收益。
- 任一入选股票缺少入场或观察价格，则整个组合收益标为不可计算，保留原名单、原分母和缺失明细。
- 只允许最近七个自然日内的信号；不会扩展到全历史回测。

## 运行

```powershell
python scripts/reconcile_d3_recommendations.py --ordinary-json temp/latest_dual_horizon_20261009.json --fusion-dir models/data/reports/dual_horizon_rrf_2026-10-09 --as-of 2026-10-13 --prices-csv outputs/01a116ce-1f0c-7d41-8967-adcca880c1b8/D3_review_20261014/prices.csv --out-dir outputs/01a116ce-1f0c-7d41-8967-adcca880c1b8/D3_review_20261014
```

价格 CSV 必须有 `symbol,date,close,source`；股票代码保留六位，`000300` 表示沪深300指数。股票使用一致的复权口径。CSV 中信号日之后的价格只用于收益核对，不参与模型训练或重新选股。

不传 `--prices-csv` 时，只导出冻结名单及需要补取的股票代码。完整 D+3 核对请以 `--as-of 2026-10-15` 运行，并提供覆盖到该日的真实行情。

## 对照与归因

主比较保留两份原始交付名单的真实数量。另输出普通名单前43只、长期 LightGBM43只、近期资金流模型43只、去掉分数 Gate 的 RRF43只，均使用信号日已经保存的分数。

这些对照是事后诊断，不能冒充当时已经交付的组合。它们能帮助区分数量、模型、Gate 和排名变化；不能单独证明资金流的增量效果。检验资金流增量还需要相同近期窗口、相同模型参数的有/无资金流比较。

单次持仓核对不计算年化收益或夏普比率，也不能提供统计显著性结论。`summary.json` 中分别记录数据是否完整、D+3 是否成熟和整体绩效状态。
