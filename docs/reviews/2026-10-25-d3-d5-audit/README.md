## 本轮实现

- `walk_forward.py`：隔离期从自然日改成交易日；按T+1+h成熟时间截断；显式日历/初步结果元数据；修正IC衰减的一天偏差及缺失bar跨越问题。
- `next_week_d3_prediction.py`：内存重算信号时可见的原始标签；交易日历决定入场/到期；取消凭训练内相关性自动晋升champion，只注册研究challenger。
- `live_multi_date_harness.py`：固定模型验证同样限制可观测成熟标签，拒绝重复/越界预测日期、未来标签因子。
- `robust_ridge.py`：原32因子保持现有归一化；最近252个成熟交易日；训练集1%/99%裁剪、StandardScaler、Ridge alpha=10；至少60有效训练日。参数在回测前固定，本轮没有择优调参。
- `compare_original_hybrid.py`：新增 `--include-robust-baseline`，生成单独的扩展等数表，不改变原四臂名单和分数文件。
- `audit_d3_d5_baselines.py`：重训48个历史信号周期（24日×2周期），两周期独立、6个交易日间隔、全臂同池、先选股后读结果、缺价整批标记无效，不补股和补零。另保存10/20快照上的两周期研究模型/名单，不能用作当前交易信号。

## 数据与证据边界

最新全池可用隔离快照为2026-10-20，299只股票；601059无截止日数据，显式排除。10/23的92只原始收盘证据不能替代全池特征、资金流与训练快照。10/20时D3标签成熟至10/14，D5至10/12。主数据湖较旧，仍主要截至10/15。

资金流组遵循现行代码：取最近120个成熟标签日期，并要求至少80个有完整资金流的日期。本轮历史有效日期数D3为82—120，D5为80—120；不能称作每次都有完整120日资金流。两组共用训练行和标签。10/20快照推理两周期均有120个有效近期日期。

计划固定24个信号。6/24的688072缺少完整持有窗口，D3/D5核心配对整期未纳入；9/8的601995使D5核心及五组配对整期未纳入。剔除发生在选股后，缺失及由此带来的样本选择限制公开记录在 `omitted_cohorts.json`。

股票池为current_only成员，存在生存者/当前成分条件偏差；行业含cninfo历史PIT区间和部分静态fallback，不能一概视为完全PIT。历史价格是10/20复权快照，跨股价格因子可能受事后复权变化影响。未证明停牌/涨跌停成交；未评8%止损臂；没有加入D3/D5跨周期融合的默示优势判断。

旧滚动验证CSV只有4个窗口，且模型与当前Ridge32+RRF不是同一流程。本次逐信号回放和5个时间分块也不冒充“5个12月滚动窗口”的主裁决。修复后的旧长短十等分回测仍是诊断口径，不能替代此次双边35bp、行业约束long-only组合。

配对区间使用2批次移动块bootstrap、5000次、固定seed=20261025；只做描述性不确定性展示，未修正多重试验。没有前瞻样本，因此晋升证据不足。
